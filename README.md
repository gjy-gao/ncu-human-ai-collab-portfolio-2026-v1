## 二、全学期 16 周实验目录树

```text
course-portfolio/                 # 仓库根目录（本仓库）
├── README.md                     # 本文件：仓库说明书 / 个人名片
├── .gitignore                    # 忽略清单：告诉 Git 哪些文件不入库
├── docs/                         # 课程文档（实验大纲、参考资料、报告模板）
│   ├── syllabus.md               #   课程大纲
│   └── report-template.md        #   实验报告模板
├── notes/                        # 每周学习笔记与心得
│   └── week-01.md ... week-16.md
├── week-01/                      # 第 1 周实验
│   ├── README.md                 #   本周实验说明（目的 / 步骤 / 结论）
│   ├── code/                     #   本周代码
│   ├── data/                     #   本周数据
│   └── report.md                 #   本周实验报告
├── week-02/                      # 第 2 周实验（结构同上）
├── week-03/
├── week-04/
├── week-05/
├── week-06/
├── week-07/
├── week-08/                      # 期中：第 1–8 周复习与整合
├── week-09/
├── week-10/
├── week-11/
├── week-12/
├── week-13/
├── week-14/
├── week-15/
├── week-16/                      # 期末综合实验 / 课程大作业
├── final-project/                # 期末综合项目（可选，用于期末大作业）
│   ├── README.md
│   ├── src/
│   └── report.md
└── assets/                       # 图片、截图、流程图等公共资源
```

**约定**：每周一个目录，目录内固定 `README.md`（说明）+ `code/`（代码）+ `data/`（数据）+ `report.md`（报告），方便老师和助教按周查阅。

## 三、每周提交规范

- 目录命名统一为 `week-01` … `week-16`（两位数字，不足补零，排序不会乱）。
- Commit 信息建议写成：`week-03: 完成数据清洗实验`，一眼能看懂做了什么。
- 大文件（超过 100 MB 的数据、视频）不要放进仓库，改用网盘链接写在报告中。

## 四、常用 Git 命令速查（新手版）

| 想做的事 | 命令 |
| :--- | :--- |
| 看看我改了哪些文件 | `git status` |
| 把改动放进"待寄包裹" | `git add .` |
| 打包并贴个说明标签 | `git commit -m "week-01: 完成第一次实验"` |
| 把包裹寄到 GitHub | `git push` |
| 把网上最新内容拉回来 | `git pull` |
| 查看提交历史 | `git log --oneline` |
